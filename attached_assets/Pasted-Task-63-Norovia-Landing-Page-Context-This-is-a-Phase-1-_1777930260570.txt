No dark mode, no stock photos, no complex animations, no App Store links, no backend calls
Mobile-first, max reading width ~680px centered on desktop
Clean sans-serif (system font stack is fine)
Rounded cards with soft shadow
CTA buttons use --color-accent with white text

Email form rules:

Controlled input (React useState)
On submit: if email is invalid show a short calm error ("Please enter a valid email"), if valid replace the whole form with the confirmation message from copy.ts
No fetch, no axios, no external service
